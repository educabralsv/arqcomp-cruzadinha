
# ARQCOMP — Cruzadinha de Arquitetura Computacional

Jogo educativo desenvolvido para a Atividade Avaliativa III da disciplina de Arquitetura Computacional, Sprint 3.

O objetivo é testar e reforçar os conhecimentos sobre componentes, tecnologias e conceitos relacionados à arquitetura dos computadores por meio de uma cruzadinha interativa.

## 🎯 Objetivo do jogo

Resolver uma cruzadinha com 16 conceitos de Arquitetura Computacional, utilizando as pistas horizontais e verticais para descobrir as palavras.

## 🕹️ Como jogar

1. Acesse o jogo pelo navegador.
2. Observe as pistas separadas em horizontais e verticais.
3. Identifique o número correspondente à pista no tabuleiro.
4. Digite uma letra em cada casa para formar a resposta.
5. Clique em **Conferir respostas** para verificar seu desempenho.
6. Acompanhe a pontuação e o progresso.
7. Utilize o botão **Reiniciar** para começar novamente.

As letras são preenchidas diretamente no tabuleiro. Os espaços compartilhados entre palavras ajudam a resolver os cruzamentos.

## 📚 Palavras e pistas utilizadas

O jogo utiliza os seguintes 16 conceitos:

| Palavra | Direção | Pista |
|---|---|---|
| MICROCONTROLADOR | Horizontal | Circuito integrado programável usado para controlar funções de equipamentos eletrônicos. |
| MEMORIADEMASSA | Vertical | Meio destinado a guardar grandes volumes de arquivos por longos períodos. |
| ADDRESSBUS | Horizontal | Conjunto de linhas que identifica a posição acessada durante uma transferência. |
| REGISTRADORES | Horizontal | Pequenos espaços internos que guardam valores usados durante o processamento. |
| ROM | Vertical | Mantém instruções gravadas mesmo quando o equipamento está desligado. |
| DUALCORE | Vertical | Configuração de processamento que reúne dois núcleos independentes. |
| DMA | Horizontal | Mecanismo que transfere informações entre periféricos e armazenamento sem controle contínuo da unidade central. |
| RAM | Horizontal | Armazena temporariamente programas e informações enquanto o equipamento está ligado. |
| UC | Horizontal | Parte que coordena a sequência de etapas durante a execução. |
| CPU | Vertical | Componente central que interpreta e executa as instruções dos programas. |
| EEPROM | Horizontal | Tecnologia cujos conteúdos podem ser apagados e regravados eletricamente. |
| QUADCORE | Horizontal | Configuração de processamento que reúne quatro núcleos independentes. |
| DATABUS | Vertical | Conjunto de linhas por onde os valores circulam entre componentes. |
| CACHE | Horizontal | Guarda cópias de informações acessadas frequentemente para acelerar consultas. |
| ULA | Vertical | Bloco responsável por operações matemáticas e decisões booleanas. |
| FLASH | Horizontal | Tecnologia de armazenamento usada em pen drives e cartões. |
